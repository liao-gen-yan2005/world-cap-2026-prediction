# 2026 世界杯球队竞争力评估与赛程预测

> 基于 AHP-CRITIC 组合赋权 + TOPSIS + Monte Carlo 仿真的赛事分析项目  
> 数学建模竞赛 · B题 · 团队项目（廖根焰 / 尹鑫怡 / 梁斯宇）

---

## 项目简介

2026年世界杯首次扩军至48支球队，赛制更复杂，预测难度显著上升。本项目基于**德转球员身价、预选赛战绩、近四届历史成绩**等多源公开数据，构建量化评估框架，系统回答三个核心问题：

1. **球队竞争力怎么量化？** — 综合评价 + 排名
2. **各队能走多远？** — 每个阶段的晋级概率
3. **结论可靠吗？** — 稳健性与敏感性验证

---

## 核心发现

| 分析维度 | 主要结论 |
|---------|---------|
| 竞争力排名 | 巴西、法国、英格兰位居前三，综合实力领先其余球队 |
| 黑马识别 | 摩洛哥、日本等队综合得分高于排名预期，具备爆冷潜力 |
| 东道主效应 | 美国/墨西哥/加拿大因主场优势晋级概率较纯实力估计提升约 8–12% |
| 八强预测 | 欧洲球队占据 5 席，南美 2 席，亚非代表 1 席概率最高 |
| 模型稳健性 | 权重扰动下 Spearman 相关系数保持 0.95 以上，排名结构稳定 |

## 技术方案

### 第一问：球队竞争力综合评价

```
原始数据（7个指标 × 48支球队）
        ↓ 正向化 + 极差标准化
AHP 主观赋权（专家判断矩阵 + 一致性检验）
        +
CRITIC 客观赋权（对比强度 × 信息量）
        ↓ KL散度最小化（几何平均归一化）
组合权重 → TOPSIS 综合评分 → 球队排名
```

**7个评价指标：**
- 全队德转总身价（百万欧元）
- 前5核心球员人均身价
- 团队均衡度（身价集中度反转）
- 预选赛场均净胜球
- 预选赛胜率
- 历史底蕴得分（近四届正赛成绩加权）
- 历史正赛场均净胜球

### 第二问：赛程模拟与晋级概率预测

```
TOPSIS 综合实力得分
        ↓ 东道主 / 地缘环境偏置修正
泊松分布建模进球数 → 单场胜负模拟
        ↓ Monte Carlo × 10,000 次
各队晋级32强 / 16强 / 八强概率分布
```

### 第三问：敏感性分析与稳健性验证

- 权重向量随机扰动（±10%、±20% 参数噪声）
- Spearman 相关性验证排名稳定性
- Jaccard 集合稳定性验证八强名单一致率

## 方法论对照表

| 模块 | 方法 | 作用 |
|------|------|------|
| 主观赋权 | AHP（层次分析法）| 引入足球领域专家知识 |
| 客观赋权 | CRITIC | 基于数据本身的信息量与差异度 |
| 权重融合 | KL 散度最小化 | 平衡主客观权重，避免单一方法偏差 |
| 综合排名 | TOPSIS | 基于正负理想解的多指标综合评价 |
| 赛程仿真 | Monte Carlo + Poisson | 量化不确定性，输出概率分布 |
| 稳健性 | 敏感性分析 + Spearman | 验证结论在扰动下的一致性 |
